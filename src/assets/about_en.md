# About SEKAI Station

SEKAI Station collects room posts tagged [#プロセカ募集](https://x.com/search?q=%23%E3%83%97%E3%83%AD%E3%82%BB%E3%82%AB%E5%8B%9F%E9%9B%86) from social media (mainly X) and shows them in real time. We do not create or publish any posts ourselves. Please judge information from outside sources with care.

Source code for some of this site's components is open source under the MIT License at https://github.com/orgs/sekai-station
